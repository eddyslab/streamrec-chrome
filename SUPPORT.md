# StreamRec Support

For questions, bug reports, or compatibility issues, use the public issue tracker:

https://github.com/eddyslab/streamrec-chrome/issues

When reporting an issue, include the StreamRec version, Chrome version, operating system,
steps to reproduce, and any non-sensitive error message. Do not include recorded media,
account credentials, cookies, private URLs, or other personal information.

Security or privacy inquiries can be sent to `jwkim@eddyslab.com`.

For Native App downloads and installation help, see the
[StreamMerger Native App guide](NATIVE_APP.md).

## 지원

질문, 오류 또는 호환성 문제는 공개 이슈 페이지에 등록해 주세요.

https://github.com/eddyslab/streamrec-chrome/issues

StreamRec 버전, Chrome 버전, 운영체제, 재현 절차와 민감하지 않은 오류 메시지를 포함하면
문제 확인에 도움이 됩니다. 녹화 파일, 계정 정보, 쿠키, 비공개 URL 또는 개인정보는
등록하지 마세요.

보안·개인정보 관련 문의: `jwkim@eddyslab.com`

Native App 다운로드와 설치 방법은 [StreamMerger Native App 안내](NATIVE_APP.md)를 확인해 주세요.
