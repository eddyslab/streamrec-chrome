# StreamRec Privacy Policy

Effective date: August 30, 2026

StreamRec records media streams from websites at the user's request and saves the resulting
media files on the user's device. This policy explains what information StreamRec processes
and how it is handled.

## Information processed by StreamRec

StreamRec may process the following information only as needed to provide its recording and
local file-processing features:

- The URL and hostname of a website on which the user enables StreamRec.
- Media resources and media segments delivered by that website.
- Recording metadata such as duration, size, resolution, segment count, filename, download
  status, and merge progress.
- User settings, including registered sites, size limits, automatic stop preferences, and
  merge preferences.
- Local diagnostic status and error messages used to show recording and conversion state.

StreamRec does not request permission to read browser passwords or authentication cookies.

## How the information is used

The information is used only to:

- Detect media streams on sites selected by the user.
- Record, combine, and save media files requested by the user.
- Display recording, download, and conversion status.
- Remember the user's local StreamRec settings.
- Diagnose failures visible to the user.

## Local processing and storage

StreamRec processes recorded media locally in Chrome. Files are saved through Chrome's
download system to a location selected or configured by the user.

Settings and limited status information are stored in Chrome extension storage on the user's
device. StreamRec does not operate a server that receives recorded media, browsing history,
or extension settings.

## Optional StreamMerger Native App

If the user installs and enables the optional StreamMerger Native App, StreamRec sends local
file paths, merge instructions, and related recording metadata to that app through Chrome's
Native Messaging interface. StreamMerger processes those files locally using ffmpeg and
returns local progress, completion, and error status to the extension.

StreamMerger may create local operational log, progress, status, preference, and socket files.
These files are not transmitted to the publisher by StreamRec.

## Data transmission and sharing

StreamRec does not sell user data. StreamRec does not transmit recorded media, browsing
activity, extension settings, or Native App status to the publisher's servers or to third
parties.

Media requests made while recording are requests to the website the user is visiting and are
necessary to access the media selected by the user. They are not sent to a StreamRec-operated
server.

## Data retention and deletion

Downloaded recordings remain on the user's device until the user deletes them.

The user can remove locally stored extension settings by removing StreamRec from Chrome or by
clearing the extension's data. Native App operational files can be deleted after quitting
StreamMerger. Removing the extension does not automatically delete downloaded recordings or
the separately installed Native App.

## User choice and responsibility

Recording starts only after the user enables a site and initiates recording. Users are
responsible for ensuring that they have permission to record and save the selected content.
StreamRec is not designed to bypass digital rights management or access controls.

## Security

StreamRec limits its use of information to its recording and local conversion purpose. The
extension's executable logic is included in the distributed extension package. The optional
Native App communicates only with authorized StreamRec extension IDs configured in its Native
Messaging manifest.

## Changes to this policy

If StreamRec's data practices change, this policy and the Chrome Web Store disclosures will be
updated before the changed practices are released.

# StreamRec 개인정보처리방침

시행일: 2026년 8월 30일

StreamRec은 사용자가 요청한 웹사이트 미디어 스트림을 녹화하고 결과 파일을 사용자의
기기에 저장합니다.

## 처리하는 정보

- 사용자가 StreamRec을 활성화한 웹사이트의 URL 및 호스트 이름
- 해당 웹사이트가 제공하는 미디어 리소스와 미디어 세그먼트
- 녹화 시간, 크기, 해상도, 세그먼트 수, 파일명, 다운로드 및 병합 상태
- 등록 사이트, 크기 제한, 자동 정지, 병합 방식 등 사용자 설정
- 녹화·변환 상태를 표시하기 위한 로컬 진단 및 오류 정보

StreamRec은 브라우저 비밀번호나 인증 쿠키를 읽는 권한을 요청하지 않습니다.

## 이용 목적과 로컬 처리

정보는 사용자가 선택한 사이트에서 미디어 스트림을 감지하고, 요청한 미디어를 녹화·병합·
저장하며, 진행 상태를 표시하고 로컬 설정을 유지하는 용도로만 사용됩니다.

녹화 미디어는 Chrome 안에서 로컬로 처리되고 Chrome 다운로드 기능을 통해 사용자 기기에
저장됩니다. 설정과 제한적인 상태 정보는 사용자 기기의 Chrome 확장 저장소에 보관됩니다.
StreamRec 운영 서버로 녹화물, 방문 기록 또는 설정을 전송하지 않습니다.

선택적으로 StreamMerger Native App을 설치한 경우 로컬 파일 경로, 병합 명령 및 진행
상태가 Chrome Native Messaging을 통해 앱과 교환됩니다. StreamMerger와 ffmpeg의 처리는
모두 사용자 기기에서 수행됩니다.

## 공유 및 판매

StreamRec은 사용자 데이터를 판매하지 않으며, 녹화 미디어·방문 활동·확장 설정·Native
App 상태를 게시자 서버 또는 제3자에게 전송하지 않습니다.

## 보관 및 삭제

다운로드한 녹화 파일은 사용자가 직접 삭제할 때까지 기기에 남습니다. 확장을 제거하거나
확장 데이터를 삭제하면 로컬 설정을 제거할 수 있습니다. 확장을 제거해도 다운로드 파일과
별도로 설치한 Native App은 자동으로 삭제되지 않습니다.

## 사용자 책임

녹화는 사용자가 사이트를 활성화하고 녹화를 시작한 뒤에만 수행됩니다. 사용자는 해당
콘텐츠를 녹화·저장할 권한이 있는지 확인해야 합니다. StreamRec은 DRM 또는 접근 통제를
우회하기 위한 제품이 아닙니다.
